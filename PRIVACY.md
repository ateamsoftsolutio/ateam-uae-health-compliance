# Privacy policy: UAE Healthcare Compliance by ATeam

Effective date: 10 October 2026

This policy covers the "UAE Healthcare Compliance by ATeam" plugin (`ateam-uae-health-compliance`), published by ATeam Soft Solutions.

## What the plugin is

The plugin contains only written instructions for Claude (skills) and a requirements library. It has no MCP servers, hooks, scripts or other code that runs on its own. ATeam doesn't run any server or service for it.

## Data ATeam collects

None. No analytics, telemetry or accounts. ATeam receives nothing from your use of the plugin.

## Data the skills handle in your Claude session

Claude reads the code, configuration, infrastructure files and documents of the project you choose to check. These can contain personal or health data, for example in test fixtures, and secrets. Claude:

- writes the checklist, run summaries and Excel exports to the `.uae-health-compliance/` folder in your project
- never displays full secret values; they are masked
- processes this content under Anthropic's terms and your account settings. ATeam has no access to it.

## Outside services

The plugin doesn't send data to any outside service. If you ask Claude to check a regulator's current website, Claude may read public web pages; no project data is sent.

## Retention

ATeam keeps nothing. The checklist and exports stay in your project until you delete them.

## Children

Not intended for anyone under 18.
